#  Módulo 02: Control de Producción - Melia


### Propósito del Módulo:

Este módulo automatiza el seguimiento de inventarios, contadores de fabricación y métricas de empaque/calidad para la elaboración de velas artesanales.

###  Archivos en este módulo:

* **`contador_melia.py`**: Registro e incremento de unidades producidas por lote.
* **`calidad_fragancias.py`**: Validación de parámetros y estándares en los insumos.
